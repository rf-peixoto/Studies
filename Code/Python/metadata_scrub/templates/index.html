    How good should the result look?

    Images and PDFs are compared against the original and compressed as hard as the level allows — the encoder setting is searched for, not guessed, because the same number means different things to a photograph and a screenshot. Video and audio use constant-quality encoding at the matching level.

    Searching costs a second or two per image. Larger batches take proportionally longer.

    download all as zip

    What gets removed. Images: EXIF, GPS, XMP, IPTC, embedded thumbnails, colour profiles and PNG text chunks — the pixel buffer is rebuilt so nothing rides along. Audio and video: container tags, stream tags, cover art and the encoder banner that x264 and x265 write inside the bitstream. PDF: DocInfo, XMP at document and page level, editor scratch data, JavaScript, auto-run actions and file attachments.

    What is kept on purpose. Photo orientation and video rotation are applied to the pixels before the metadata describing them is deleted, so nothing ends up sideways. Colour profiles are converted to sRGB first, so colours do not shift. Indexed palettes are carried across, because a palette is the picture rather than a note about it.
